This chapter provides the theoretical foundation for discrete-time dynamical systems and Model Predictive Control (MPC), 
which serves as the expert policy for the imitation learning framework used in this work. First, \cref{sec:discrete-sys-stability} 
introduces discrete-time dynamical systems, state and input constraints, and the core principles of Lyapunov stability. 
Afterwards, \cref{sec:mpc-stability} outlines the constrained finite-horizon optimal control problem and details the 
terminal ingredients required to guarantee asymptotic stability of the closed-loop system.
