\section{Model Predictive Control and Stability}
\label{sec:mpc-stability}

This section summarizes the Model Predictive Control (MPC) framework and 
the conditions required to guarantee closed-loop stability in finite-horizon optimal control setups.


\subsection{Problem Formulation}
\label{subsec:mpc-problem}

For the nominal MPC setup considered in this work, the following finite-horizon optimal control problem  
is solved at each time step $k$ given the current system state $x_k$ \citeSec{2.2}{rawlingsModelPredictiveControl2020}:
\begin{equation}
    \label{eq:mpc-problem}
    \begin{aligned}
        \min_{\{x_i\}_{i=0}^N, \{u_i\}_{i=0}^{N-1}} \quad &
        \sum_{i=0}^{N-1} \ell(x_i, u_i) + V_f(x_N) \\
        \text{s.t.} \quad & x_{i+1} = f_d(x_i, u_i), && i = 0, \dots, N-1, \\
        & x_i \in \mathcal{X}, && i = 0, \dots, N, \\
        & u_i \in \mathcal{U}, && i = 0, \dots, N-1, \\
        & x_0 = x_k.
    \end{aligned}
\end{equation}
Here, $N$ denotes the prediction horizon, $\ell(x_i, u_i)$ is the stage cost function, and $V_f(x_N)$ represents the terminal cost function. 
The system dynamics are represented by the discrete-time function $f_d(x_i, u_i)$, 
while $\mathcal{X}$ and $\mathcal{U}$ denote the state and input constraint sets, respectively. 

A quadratic cost function is used for the stage cost, defined as 
\begin{equation}
    \label{eq:stage-cost}
    \ell(x_i, u_i) = x_i^\top Q x_i + u_i^\top R u_i,
\end{equation}
where $Q \succ 0$ and $R \succ 0$ are the state and input weighting matrices, respectively \citeSec{1.3}{rawlingsModelPredictiveControl2020}. 
Following the receding horizon principle, only the first control input $u_0^*$ from the optimal sequence is applied to the system, 
and the optimization is repeated at the next sampling instance \citeSec{2.2}{rawlingsModelPredictiveControl2020}.


\subsection{Terminal Ingredients for Stability}
\label{subsec:terminal-set-cost} 

To guarantee closed-loop stability in nominal MPC, the optimal control problem \cref{eq:mpc-problem} is augmented 
with a terminal constraint $x_N \in \mathcal{X}_f$, where $\mathcal{X}_f \subseteq \mathcal{X}$ denotes the terminal set, 
and a terminal cost function $V_f(x_N)$ \citeAsm{2.14}{rawlingsModelPredictiveControl2020}:
\begin{equation}
    \label{eq:terminal-constraint}
    x_N \in \mathcal{X}_f.
\end{equation}  

A set $\mathcal{X}_f$ is positively invariant under a local control law $u = \pi(x_k)$ if any trajectory originating in $\mathcal{X}_f$ 
remains inside the set for all future time steps \citeDef{2.9}{rawlingsModelPredictiveControl2020}:
\begin{equation}
    \label{eq:positive-invariance}
    f_d(x, \pi(x)) \in \mathcal{X}_f
    \quad \text{and} \quad
    \pi(x) \in \mathcal{U},
    \qquad \forall x \in \mathcal{X}_f.
\end{equation}

The predictive mechanism is illustrated in \cref{fig:terminal-set-comparison}. 
While the intermediate states $x_0, \dots, x_{N-1}$ are merely constrained to the safe state space $\mathcal{X}$, 
the terminal constraint \cref{eq:terminal-constraint} enforces $x_N \in \mathcal{X}_f$. 
Together with the terminal cost $V_f(x_N)$ acting as a local Lyapunov function, 
these ingredients guarantee closed-loop asymptotic stability over an infinite horizon \citeThm{2.19}{rawlingsModelPredictiveControl2020}.

For nonlinear systems, the terminal set $\mathcal{X}_f$ is typically computed using linearized system dynamics around the equilibrium point 
$(x, u) = (\mathbf{0}, \mathbf{0})$, yielding the linear discrete-time model:
\begin{equation}
    \label{eq:linearized-system}
    x_{k+1} = A x_k + B u_k.
\end{equation}
A widely used choice for these terminal ingredients is then derived from the Linear-Quadratic Regulator (LQR) \citeEq{1.18}{rawlingsModelPredictiveControl2020}. 
Here, the local control law $\pi(x_k)$ is chosen as a linear state-feedback policy $\pi(x_k) = -K x_k$, where the optimal LQR gain $K$ is given by
\begin{equation}
    \label{eq:lqr-feedback}
    K = \left(R + B^\top P B\right)^{-1} B^\top P A.
\end{equation}

Under the standard stabilizability and detectability assumptions, the matrix
$P \succ 0$ is obtained as the unique stabilizing solution to the discrete-time
Algebraic Riccati Equation (DARE) \citeEq{1.18}{rawlingsModelPredictiveControl2020}:
\begin{equation}
    \label{eq:riccati-equation}
    P = A^\top P A - A^\top P B \left(R + B^\top P B\right)^{-1} B^\top P A + Q.
\end{equation}

This matrix parameterizes the quadratic terminal cost function $V_f(x_N) = x_N^\top P x_N$. 
Accordingly, the terminal set $\mathcal{X}_f$ is defined as an ellipsoidal sub-level set of 
this cost function \citeSec{2.5.5}{rawlingsModelPredictiveControl2020}:
\begin{equation}
    \label{eq:terminal-ellipse}
    \mathcal{X}_f := \left\{ x \in \mathbb{R}^n \ \middle|\ x^\top P x \leq \alpha \right\}.
\end{equation}
Choosing the scaling parameter $\alpha > 0$ sufficiently small guarantees that $\mathcal{X}_f$ 
satisfies both the state and input constraints $\mathcal{X}$ and $\mathcal{U}$ 
while ensuring that the quadratic Lyapunov decrease dominates higher-order 
linearization errors of the nonlinear dynamics.

\subsection{Closed-Loop Stability}
\label{subsec:closed-loop-stability}

Under the MPC policy $\pi_{\mathrm{MPC}}(x_k) := u_0^*(x_k)$, 
the optimal value function $V_N^*(x_k)$ of \cref{eq:mpc-problem} serves as a Lyapunov candidate 
over the feasible set $\mathcal{X}_N \subseteq \mathcal{X}$ \citeSec{2.4.2}{rawlingsModelPredictiveControl2020}. 
Using the terminal ingredients from \cref{subsec:terminal-set-cost}, the recursive
feasibility at time step $k+1$ is determined by using the remaining inputs of the optimal sequence 
computed at time step $k$ and appending the terminal control action $\pi(x_N^*)$ \citeSec{2.4.2}{rawlingsModelPredictiveControl2020}.
Consequently, $V_N^*$ satisfies a decrease condition along closed-loop trajectories, 
expressed with the relaxed Lyapunov decrease formulation:
\begin{equation}
    \label{eq:relaxed-mpc-stability}
    V_N^*(f_d(x_k, \pi_{\mathrm{MPC}}(x_k))) \leq V_N^*(x_k) - \alpha_N \cdot \ell(x_k, \pi_{\mathrm{MPC}}(x_k)), \qquad \forall x_k \in \mathcal{X}_N,
\end{equation}
where $\alpha_N \in (0, 1]$ denotes the relaxed decre factor \citeAsm{2.14}{rawlingsModelPredictiveControl2020}. 
Setting $\alpha_N = 1$ yields the standard nominal Lyapunov decrease
\begin{equation}
    V_N^*(x_{k+1}) - V_N^*(x_k) \leq -\ell(x_k, \pi_{\mathrm{MPC}}(x_k)),
\end{equation}
guaranteeing asymptotic stability of the origin $\mathbf{0}$ for all initial states $x_0 \in \mathcal{X}_N$ \citeThm{2.19}{rawlingsModelPredictiveControl2020}.
