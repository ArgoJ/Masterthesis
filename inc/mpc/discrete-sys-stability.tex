\section{Discrete-Time Dynamical Systems and Stability}
\label{sec:discrete-sys-stability}

Implementing optimal control schemes on digital hardware requires a discrete-time representation. 
Consequently, the continuous-time dynamics
\begin{equation}
    \label{eq:continuous-time-system}
    \dot{x}(t) = f(x(t), u(t))
\end{equation}
must be discretized, where $x(t) \in \mathcal{X} \subseteq \mathbb{R}^{n_x}$ and 
$u(t) \in \mathcal{U} \subseteq \mathbb{R}^{n_u}$ denote the continuous-time state and input vectors, respectively, 
with state space dimension $n_x \in \mathbb{N}$ and input dimension $n_u \in \mathbb{N}$.
In this work, the corresponding discrete-time system
\begin{equation}
    \label{eq:discrete-time-system}
    x_{k+1} = f_d(x_k, u_k)
\end{equation}
is obtained by approximating the continuous dynamics using a numerical integration scheme with a constant sampling time $T_s > 0$. 
Here, $k \in \mathbb{N}_0$ denotes the discrete time step index, such that $x_k := x(k T_s) \in \mathcal{X}$ and 
$u_k := u(k T_s) \in \mathcal{U}$ represent the state and control input at time $k T_s$. 
The discrete-time function $f_d: \mathcal{X} \times \mathcal{U} \to \mathcal{X}$ is evaluated using a 
numerical integration scheme, such as the forward Euler or a fourth-order Runge-Kutta (RK4) method 
\cite{butcherNumericalMethodsOrdinary2016}.


\subsection{Lyapunov Stability}
\label{subsec:lyapunov-stability}

Consider the discrete-time closed-loop system under a state-feedback control policy 
$\pi: \mathcal{X} \to \mathcal{U}$ with the origin $x = \mathbf{0}$ as an equilibrium point, 
satisfying $\pi(\mathbf{0}) = \mathbf{0}$ and $f_d(\mathbf{0}, \mathbf{0}) = \mathbf{0}$.
Assuming the state constraint set $\mathcal{X}$ is positively invariant under $\pi$, 
the origin is \textit{Lyapunov stable} in $\mathcal{X}$ if there exists a positive definite function 
$V: \mathcal{X} \to \mathbb{R}_{\ge 0}$ satisfying \citeThm{2.13}{rawlingsModelPredictiveControl2020}:
\begin{equation}
    \label{eq:lyapunov-stability}
    \begin{aligned}
        V(\mathbf{0}) &= 0 \qquad && \\
        V(x) &> 0 \qquad && \forall x \in \mathcal{X} \setminus \{\mathbf{0}\} \\
        V(f_d(x, \pi(x))) - V(x) &\leq 0 \qquad && \forall x \in \mathcal{X} \setminus \{\mathbf{0}\}.
    \end{aligned}
\end{equation}

If the decrease condition holds strictly along closed-loop trajectories,
\begin{equation}
    \label{eq:asymptotic-lyapunov-stability}
    V(f_d(x, \pi(x))) - V(x) < 0 \qquad \forall x \in \mathcal{X} \setminus \{\mathbf{0}\},
\end{equation}
the origin is \textit{locally asymptotically stable}, guaranteeing trajectory
convergence to the origin for all initial states $x_0$ in a sufficiently small
neighborhood of the origin \citeThm{2.13}{rawlingsModelPredictiveControl2020}.
