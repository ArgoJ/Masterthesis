\section{Discrete-Time Dynamical Systems and Stability}
\label{sec:discrete-sys-stability}

Implementing optimal control schemes on digital hardware requires a discrete-time representation. 
Consequently, the continuous-time dynamics
\begin{equation}
    \label{eq:continuous-time-system}
    \dot{x}(t) = f_c(x(t), u(t))
\end{equation}
must be discretized, where $x(t) \in \mathbb{R}^{n_x}$ and 
$u(t) \in \mathbb{R}^{n_u}$ denote the continuous-time state and input vectors, respectively, 
with state space dimension $n_x \in \mathbb{N}$ and input dimension $n_u \in \mathbb{N}$.
In this work, the corresponding discrete-time system
\begin{equation}
    \label{eq:discrete-time-system}
    x_{k+1} = f(x_k, u_k)
\end{equation}
is obtained by approximating the continuous dynamics using a numerical integration scheme with a constant sampling time $T_s > 0$. 
Here, $k \in \mathbb{N}_0$ denotes the discrete time step index, such that $x_k := x(k T_s) \in \mathbb{R}^{n_x}$ and 
$u_k := u(k T_s) \in \mathbb{R}^{n_u}$ represent the state and control input at time step $k$. 
The discrete-time function $f: \mathbb{R}^{n_x} \times \mathbb{R}^{n_u} \to \mathbb{R}^{n_x}$ is evaluated using a 
numerical integration scheme, such as the forward Euler or a fourth-order Runge-Kutta (RK4) method~
\cite{butcherNumericalMethodsOrdinary2016}.

To account for physical and operational limitations, the system states and control inputs are restricted to 
constraint sets $\mathcal{X} := [\underline{x}, \overline{x}] \subseteq \mathbb{R}^{n_x}$ and 
$\mathcal{U} := [\underline{u}, \overline{u}] \subseteq \mathbb{R}^{n_u}$. 
Furthermore, without loss of generality, any equilibrium $(x^\star, u^\star)$ can be shifted to the origin 
via deviation variables $\tilde{x} := x - x^\star$ and $\tilde{u} := u - u^\star$. For readability, 
the tilde notation is subsequently dropped, so that $x$ and $u$ represent the shifted variables, 
assuming $(x^\star, u^\star) = (\mathbf{0}, \mathbf{0})$ throughout this work.


\subsection{Lyapunov Stability}
\label{subsec:lyapunov-stability}
Consider the discrete-time closed-loop system under a state-feedback control policy 
$\pi: \mathcal{X} \to \mathcal{U}$. The origin serves as an equilibrium point  $x^\star = \mathbf{0}$ 
satisfying $\pi(\mathbf{0}) = \mathbf{0}$ and $f(\mathbf{0}, \mathbf{0}) = \mathbf{0}$.
Assuming the compact state constraint set $\mathcal{X}$ is positively forward invariant under $\pi$, 
the origin is locally asymptotically stable in $\mathcal{X}$ if there exists a continuous, positive definite function 
$V: \mathcal{X} \to \mathbb{R}_{\ge 0}$ satisfying~\citeThm{2.13}{rawlingsModelPredictiveControl2020}:
\begin{equation}
    \label{eq:asymptotic-lyapunov-stability}
    \begin{aligned}
        V(\mathbf{0}) &= 0, \\
        V(x) &> 0 \qquad && \forall x \in \mathcal{X} \setminus \{\mathbf{0}\}, \\
        V(f(x, \pi(x))) - V(x) &< 0 \qquad && \forall x \in \mathcal{X} \setminus \{\mathbf{0}\}.
    \end{aligned}
\end{equation}
Here, the decrease condition ensures that any trajectory starting in $\mathcal{X}$
remains bounded within $\mathcal{X}$ and asymptotically converges towards the equilibrium $x^\star = 0$.
