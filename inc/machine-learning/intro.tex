In imitation learning, artificial neural networks (ANNs) approximate complex control laws offline 
to bypass the computational overhead of online Model Predictive Control (MPC) evaluations. 
As the machine learning foundation for this work, 
\cref{sec:ann} introduces the basic architecture of Multi-Layer Perceptrons (MLPs), 
loss functions, backpropagation, and gradient-based optimization methods. 
Afterwards, \cref{sec:adversarial-examples} presents adversarial example generation and 
Projected Gradient Descent (PGD), which serve to identify counterexamples to the Lyapunov conditions.
