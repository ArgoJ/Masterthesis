# LaTex Vorlage für Abschlussarbeiten am rtm

Dieses Dokument beinhaltet allgemeine und LaTeX-spezifische Hinweise zur Durchführung einer wissenschaftlichen Arbeit und Erstellung einer schriftlichen Ausarbeitung am IAT.
Es ist ein Fork von und basiert auf dem Repository [tuda-ci_vorlage](https://git.rtm.e-technik.tu-darmstadt.de/tuda-ci_templates/tuda-ci_vorlage).


# need to be installed

```bash
sudo apt install \
texlive \
texlive-lang-german \
texlive-luatex \
latexmk \
texlive-publishers \
texlive-latex-extra \
texlive-science \
biber \
texlive-fonts-extra \
texlive-fonts-recommended
```
